# Dicedoku

A Yahtzee × Sudoku dice-pool game: roll, hold and lock dice, place them on a procedurally generated
sudoku grid, buy dice and curses from a raccoon merchant, and race your friends.

| Folder | What | Owner agent |
|---|---|---|
| `godot/` | Official game, Godot 4 (v0.9+) | code (`godot/assets/`: assets) |
| `docs/design/` | Game design document and specs | design |
| `docs/assets/` | Style guide and asset list | assets |
| `docs/tech/`, `docs/RELEASES.md` | Architecture and release notes | docs |
| `prototype-web/` | Frozen web prototype v0.8.1 and its dev log | — (reference only) |
| `CHANGELOG.md` | The single log every agent writes to | all |

Tests run in GitHub Actions on every push (`.github/workflows/tests.yml`).
