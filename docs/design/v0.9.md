# v0.9 scope — first Godot version

Source of truth for the rules: `prototype-web/dicedoku-v0.8.1.html` (see `prototype-web/DEVLOG-web.md`), with the changes below.

## Rule changes from web v0.8.1
1. **No d20.** Upgrade chain is d4 → d6 → d8 → d10 (Whetstone on a d10: "already the strongest die").
   The only wild is the d10's zero. Shop and rules text drop every d20 mention.
2. **Local pass-and-play** (1–4 players on one device). Online multiplayer is a later milestone.
   - Turns go in seat order; finished or eliminated players are skipped.
   - Between turns a "Pass the device to <name>" screen hides the board until the next player taps "Ready".
   - No Skip button (everyone is at the same device).
   - Curses go into the target's pending list and hit their next first roll, exactly as in v0.8.1. Ward blocks one.
3. **Pets** (cosmetic in v0.9): each seat picks one of Kitten Wizard, Puppy Knight, Fox Rogue, Bunny Bard.
   Their portrait appears on the turn banner, the pass screen and the players list. Two seats may not pick the same pet.
4. **The merchant is Rook, a raccoon** in a hooded cloak with a lantern; his portrait heads the shop panel.

## Unchanged from v0.8.1 (port exactly)
Puzzle generator (same seed → same puzzle as the web prototype), grids 4/6/9 with givens 6/14/34,
starting dice (5×d4, 5×d6, 5×d6), 3 rolls, hold max 5, roll → lock → place, mistakes (3 = lost), hints and combos
(first five dice: five of a kind = 2 hints, run of 4 = 1, on 9×9 a triple = 1), wild/dead faces, completed-number marks,
gold (+1 per hit, +2 more with Golden, +1 for a turn with no placements), merchant (Whetstone + one versus item + 1–3 random,
same stock for everyone on a given turn), dice abilities (Mirror, Safe, Golden, Loaded), pool max 9,
curses Hex / Blight / Shackle and Ward, score = turns + 2 × mistakes.

## Look and feel
Cozy fantasy tavern UI over an inked dungeon map.
- Board: stone floor tiles; thick wall lines between boxes; givens look carved into the stone;
  placed numbers glow like torchlight; legal cells for the selected die glow softly.
- Dice: glowing gems shaped by type (d4 triangle, d6 square, d8 diamond, d10 kite), number drawn on top;
  held = golden rim, used = faded, dead = cracked/grey, wild = sparkle.
- Panels: parchment on wood. Curses: purple sparkle.
- Palette: parchment #F1E3C6, ink #3B2A1A, wood #6B4426, stone #8A8580, torch #FFB347, curse #8E44AD,
  gold #E2B33C, mistake red #B5442C, ok green #4E8A3E. Portrait layout 720×1280.
